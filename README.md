A tiny stack virtual machine for make.fun's [Build a tiny stack virtual machine, 22 November 2026](https://make.fun/bounty/tiny-stack-vm-01-run-20261122) bounty ($100 in USDC). `main.ts` (Node 22) runs all 40 programs of a set in one run, implementing the tiny stack ISA: 32-bit wrapping arithmetic, 256-value stack, calls, 256 words of memory, input/output, and traps 2–11.
